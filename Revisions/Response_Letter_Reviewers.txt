RESPONSE TO REVIEWER 1
------------------------------------------------------------------------

Comment 1. The implemented features are derived from persistent homology (Betti curves via Ripser), not from persistent Stanley-Reisner theory. The manuscript should either provide a genuine PSRT implementation or remove the PSRT discussion and rename the method.

Response. We thank the reviewer for this important distinction. The revised manuscript restructures Section 3.3 to make the relationship unambiguous. Persistent homology (PH), computed via Ripser, is now introduced as the operative computational method in Section 3.3.1. Stanley-Reisner (SR) theory is presented in Sections 3.3.2-3.3.5 as the algebraic framework that motivates the bipartite element-specific descriptor design, following Feng et al. and Suwayyid and Wei. Importantly, Section 3.4.3 now describes a genuine SR-theoretic computation: persistent f-vectors and h-vectors derived from a strict bipartite distance filtration. These are computed separately from the PH Betti curves, evaluated independently in the ablation study (Table 4), and referred to as the PSRT component throughout. Section 3.3.5 explicitly states that the full-complex beta-0 and beta-1 from Ripser serve as a tractable proxy for the persistent SR graded Betti numbers defined in Equation (20). The name CAML-RNA is retained because the framework genuinely integrates both PH and PSRT components.

Comment 2. The comparison is unfair: CAML-RNA uses LOO-CV while competing methods use 10-fold CV.

Response. This is a valid concern and we have addressed it directly. We now report a nested 10-fold cross-validation result for CAML-RNA (outer 10-fold, inner 5-fold for hyperparameter tuning): R = 0.6255. This result is included in Table 1 alongside the LOO result (Evaluation Protocol: LOO-CV; 10-fold CV; Pearson R: 0.7283 (LOO); 0.6255 (10-fold)). Section 2.1 now explicitly compares on equal terms: under 10-fold CV, CAML-RNA achieves R = 0.6255 versus DeepMIF R = 0.773 on the same NA-L database. The text explains that LOO-CV maximises available training data per prediction and is therefore particularly appropriate for small datasets (n = 143), but both results are now reported transparently.

Comment 3. A comprehensive ablation study is needed to quantify the contribution of each feature modality.

Response. Table 4 and Section 2.4 present a complete modality ablation across 13 feature combinations under nested 10-fold CV. Results are reported for each single modality: PH Betti curves (R10 = 0.613), PSRT f/h-vectors (R10 = 0.535), CPF (R10 = 0.300), RNA-FM (R10 = 0.334), Morgan fingerprints (R10 = 0.518), and physicochemical descriptors (R10 = 0.456). All pairwise and higher-order combinations are also reported. Figure 5 provides a visual summary.

Comment 4. References to Step 4 and Step 33 are unclear and should be defined.

Response. A paragraph has been added to Section 3.6 defining the numbered stages. The CAML-RNA pipeline comprises 33 sequential computational stages: Steps 1-4 construct the baseline feature modalities (ES Betti curves, CS Betti curves, PSRT f/h-vectors) and the global SVR model; Steps 5-15 explore additional modalities individually and in combination; Steps 16-33 apply and refine the subtype-aware override strategy, including riboswitch subclass-level refinements and sign correction for anti-correlated subgroups. The final model (Step 33) integrates all overrides. All 33 stages are implemented in the public code repository.

We thank Reviewer 2 for the rigorous mathematical analysis. These comments have directly improved the precision of the methods section.

Comment 1. The Vietoris-Rips construction in Equation (21) does not mathematically exclude intramolecular RNA-RNA or ligand-ligand edges, as claimed in the text.

Response. The reviewer is correct. The relevant passage in Section 3.2 has been revised to accurately reflect what the construction achieves. The PSRT f/h-vector features (Section 3.4.3) use a strict bipartite distance filtration in which all intramolecular atom-atom distances are set to infinity, so that only intermolecular RNA-ligand edges form. The PH Betti curve features (Sections 3.4.1-3.4.2) use element-specific VR filtrations over the union of element-selected RNA and ligand atom subsets; intramolecular edges between same-element atoms may form within the VR complex, but their contribution to the Betti curves is dominated by the intermolecular signal at the filtration levels relevant to molecular recognition (r >= 3 angstroms), owing to the element-specific channel design that separates RNA and ligand element types into dedicated pair channels. The prior claim that intramolecular contacts are completely excluded has been corrected; it applied only to the PSRT component.

Comment 2. There is a fundamental mismatch between the persistent SR graded Betti numbers described mathematically and the quantities actually computed (PH Betti curves from Ripser).

Response. We agree and have corrected this throughout the manuscript. Section 3.3.1 now clearly introduces PH as the operative computational method. Sections 3.3.2-3.3.5 present SR theory as the algebraic framework motivating the descriptor design. Section 3.3.5 explicitly states that CAML-RNA uses full-complex beta-0 and beta-1 from Ripser as a tractable proxy, while the SR algebraic structure motivates the bipartite design. The PSRT label in the manuscript is reserved for the f/h-vector features in Section 3.4.3, which are genuine SR-theoretic invariants computed directly. Graded Betti numbers requiring Macaulay2 or equivalent software are not claimed to be computed.

Comment 3. The interpretation that Betti-0 decay corresponds to the SR ideal acquiring minimal generators is incorrect. As the filtration parameter increases, the complex gains faces, nonfaces are removed, and the SR ideal loses generators.

Response. The reviewer is correct. The revised text in Section 4 states that each edge added to the complex eliminates one degree-2 nonface from the SR ideal, so rapid beta-0 decay reflects a rapidly shrinking SR ideal. The earlier directional error has been corrected.

Comment 4. A 1-dimensional homology class cannot be directly identified with a cubic minimal generator of the SR ideal.

Response. We agree that the earlier phrasing overstated the correspondence. The revised text (Section 4) now reads: the beta-1 peak corresponds to a 1-dimensional hole which, via Hochster's formula, is consistent with the presence of degree-3 generators in the SR ideal. The minimal vertex support of a 1-cycle in the bipartite complex contains three vertices, so the corresponding nonface contributes a degree-3 monomial. The text explicitly notes that this is not a strict bijection between individual beta-1 classes and cubic generators but a physically grounded algebraic interpretation of the persistent enclosure geometry.

Comment 5. The 660-dimensional contact pair feature vector is not sufficiently explained.

Response. Section 3.5 now provides the complete derivation: 11 RNA chromatic atom types (C/N/O/P in backbone, base, or sugar context, plus one catch-all type) times 10 ligand element types (C, N, O, S, P, F, Cl, Br, I, other) times 6 distance cutoffs (3.5, 4.0, 4.5, 5.0, 5.5, and 6.0 angstroms), giving 11 x 10 x 6 = 660 features.

Comment 6. Hydrogen is listed as a ligand atom type despite being described as a heavy atom.

Response. Section 3.4.1 now explicitly states that the nine ligand element types exclude hydrogen because RDKit strips polar hydrogens and hydrogen-only channels carry no signal. The definition of the vertex set in Section 3.2 refers consistently to heavy atoms throughout.

Comment 7. The mathematical notation and typesetting require substantial correction.

Response. The complete mathematical section has been carefully re-typeset and independently verified. All equations covering the polynomial ring definition, homology groups, Betti numbers, graded Betti numbers, Hochster's formula, f-vector, Hilbert series, h-vector, filtration, and persistent SR Betti numbers have been checked for completeness of symbols, subscripts, superscripts, and summation indices.

RESPONSE TO REVIEWER 3
------------------------------------------------------------------------

We thank Reviewer 3 for the focused and constructive comments.

Comment 1. It is unclear which specific Suwayyid-Wei invariants are used.

Response. Section 3.4.3 now specifies that CAML-RNA computes persistent f-vectors and h-vectors following Suwayyid and Wei. For each of the 72 atom-type pairs (36 ES + 36 CS), the filtration-dependent intermolecular edge count f1(r) and the derived h-vector component h2(r) are computed at 24 radii, together with four scalar summaries of the f1 curve (area under curve, maximum, maximum rate of increase, and fill density). This yields 52 features per pair and 3744 PSRT features in total. The reference to Suwayyid and Wei is cited in the abstract and in Section 3.4.3.

Comment 2. An ablation study is needed to assess the separate contributions of persistent homology and the Suwayyid-Wei invariants.

Response. Table 4 and Section 2.4 present a complete ablation. PH Betti curves alone achieve R10 = 0.613; PSRT f/h-vectors alone achieve R10 = 0.535; their combination achieves R10 = 0.547. The text explains that PH is the stronger standalone predictor and that the f1(r) curve is highly correlated with the beta-0 Betti curve, accounting for the limited gain from their combination. However, PSRT provides complementary signal when combined with RNA-FM embeddings (PH+PSRT+RNA-FM: R10 = 0.628).

Comment 3. Comparing methods across datasets of substantially different sizes is not justified.

Response. We agree that direct performance comparison across the NA-L (n = 117-143) and R-SIM (n = 1439-1524) datasets is not appropriate, and the revised manuscript states this explicitly. The Table 1 footnote now reads: direct comparison with NA-L-based methods is not appropriate owing to differences in database size, composition, and subtype distribution. The primary performance comparison in Section 2.1 is restricted to the three methods evaluated on the same NA-L database (AffiGrapher, RLaffinity, RLASIF, and DeepMIF). RSAPred and DeepRSMA are included in Table 1 as reference points only.

Comment 4. The distinction between 10-fold random CV and 10x random CV is not clearly defined.

Response. Table 1 now uses consistent terminology: LOO-CV for leave-one-out cross-validation and 10-fold CV for 10-fold cross-validation. Section 2.1 clarifies that certain benchmark methods reported results from 10 repeated random train-test partitions rather than a standard 10-fold CV; where this distinction exists, it is noted in the Evaluation Protocol column using the protocol reported in the original publication.

Comment 5. Listing different data-splitting schemes side by side does not support meaningful conclusions about method effectiveness.

Response. Section 2.1 has been revised to make the intent explicit. The text now distinguishes three groups in Table 1: (1) NA-L methods using LOO-CV (AffiGrapher, RLASIF, CAML-RNA), which are directly comparable; (2) NA-L methods using 10-fold CV (RLaffinity, DeepMIF), for which CAML-RNA's 10-fold result (R = 0.6255) is now also reported; and (3) R-SIM methods (RSAPred, DeepRSMA), which are included for reference and are explicitly noted as not directly comparable. The conclusion stated in Section 2.1 is restricted to the NA-L comparable group.

Comment 6. Equations (3), (4), (5), (10), and (15) appear to have gaps or missing terms.

Response. All five equations have been re-typeset and verified. Equation (3) defines the persistent Betti number as the dimension of the n-th homology group of VR(X,r) over field k. Equation (4) defines the polynomial ring with the natural grading. Equation (5) defines the SR ideal as generated by square-free monomials corresponding to nonfaces. Equation (10) defines the graded Betti numbers via Tor. Equation (15) defines the Hilbert series and its h-vector decomposition. All symbols, subscripts, and summation indices are complete in the revised manuscript.
